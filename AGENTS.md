# Course production instructions

For AWS Security Specialty image work, use `VISUAL_STANDARD=AIP_SECURITY_GLOSS_V1`.

Before generating or publishing, read:
- `docs/scs-c03/AIP_SECURITY_GLOSS_V1.md`
- `docs/scs-c03/module-01-production.json`
- `app/courses/aws-security-specialty/visual-plan.json`

The approved standard is the dark navy glossy Security variant of AIP, referenced by Module 01 slides 25–28. Review its actual image assets before a new batch. Preserve readable supporting text, rich service colors, recognizable icons, meaningful connectors and varied instructional layouts. Reject white-background deviations, empty icon boxes, fake AWS wordmarks and incorrect API/data-flow directions.

Preserve original slide numbers and source mappings. Display Module 01 corresponds to planning Module 08 (advanced IAM); exam-domain numbers are a different system. Map only reviewed existing assets. Do not declare the module complete while earlier assets or objective coverage remain unresolved.

Normally publish 20–25 accepted images together, maximum 30. An explicit request to push pending or recovered work authorizes a smaller recovery batch. Verify the current remote branch and image blob hashes before reporting publication. Keep unrelated course changes out of a Security commit.
