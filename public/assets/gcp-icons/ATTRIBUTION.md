# Google Cloud icons

Official source: https://cloud.google.com/icons

Retrieved 2026-09-26 from the core product, product category, and legacy console ZIP downloads linked by Google. SVG bytes are unchanged; filenames and folders are normalized. Google and Google Cloud names and marks belong to Google LLC. These assets do not imply endorsement.

The source page identifies the new core/category icon system as introduced in early 2025. Legacy console icons are retained only as explicitly labeled legacy assets. Category icons must not be presented as unique service logos.

See `docs/gcp/icon-manifest.json` for source URLs, archive SHA-256 hashes, original archive paths, per-file hashes, and service mappings.
