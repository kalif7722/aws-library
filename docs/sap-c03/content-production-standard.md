# SAP-C03 content production standard

Approved reference: Module 09 and earlier modules. Applies to revisions and Module 11 onward.

1. Inventory every source PDF page, heading, subtopic, number, qualifier, diagram-only relationship, example and exception before generating visuals. Keep a page-to-lesson crosswalk.
2. Teach with original explanations and original diagrams. Do not republish the source slides or their wording.
3. Follow Module 09: dark navy background, compact module/slide label, strong white/amber title, named cyan sections, thin panel outlines, explanatory prose, meaningful service diagrams and one Remember takeaway. Gloss is acceptable on icons; scenery must not consume teaching space.
4. Name protocols, permissions, failure boundaries, prerequisites, operational steps, recovery behavior and common exam traps. Include a worked comparison when a broad summary would hide a decision.
5. Put exact comparisons and long limits in readable native tables following the Module 09 reference format. Notes alone do not close a missing visual teaching topic. A table supports a visual explanation; it does not substitute for every missing core concept.
6. Verify changeable specifications and feature availability against primary AWS documentation. Date the verification. Explicitly disposition obsolete PDF numbers, retired products and restricted new-customer availability. Do not silently retain old maxima or remove the underlying concept.
7. Inspect the actual published asset, including diagram arrows, labels, order of operations and matching lesson metadata. Generation success, OCR success and lesson count are not semantic coverage evidence. Regenerate incorrect assets.
8. Decode every active asset, check dimensions and nonzero size, confirm unique identifiers/sequences and valid paths, review text and layout, build the application and run relevant existing checks.
9. Record accepted evidence per source item and retain unresolved items visibly. Never infer 100% course coverage from module status or image counts. Future modules remain planned until the same gate is met.
10. Finish the current module and repair discovered earlier gaps before beginning the next module.
