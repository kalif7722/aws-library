# SAP-C03 full-length rehearsal

A separate single bank of 75 new, independently authored cases. It is not official exam content and no raw percentage is interpreted as an AWS scaled score or a pass prediction.

- In Exam mode, use one 180-minute wall-clock session. Learners can flag answers and navigate, but answer keys, sources, visuals, and the identity of the unscored items appear only after submission or when time expires.
- In Practice mode there is no timer; checking an item locks that response and allows its explanation and visual. The mode stays fixed until explicitly finishing and starting a new attempt. Progress stores in this browser, independently of the existing 28-item diagnostic.
- Each form has 65 scored items distributed 16/16/10/10/13 across the five AWS SAP-C03 domains (25/25/15/15/20), plus 10 unscored. Rounding is applied to the scored items. This is one bank; changes in order and unscored slots do not create a second unseen set. Taking Practice first exposes the same scenarios.
- Related course visuals are mapped by actual SAP lesson ID and point to the published course assets. They illustrate the deciding concepts, not official answer diagrams.
- The [AWS SAP-C03 exam guide](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-professional-03/solutions-architect-professional-03.html) defines domain weights and option formats.
