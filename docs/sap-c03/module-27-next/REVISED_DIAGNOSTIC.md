# Revised SAP-C03 diagnostic
The 28-question diagnostic is a compact course assessment, not a certification exam or pass prediction. The five supplemental cases are practice only. The 75-question mock is not enabled.

The current AWS SAP-C03 exam guide gives domain weights of 25%, 25%, 15%, 15%, and 20%; the short diagnostic uses 7, 7, 4, 4, and 6 questions respectively after rounding. Each item is independently authored and follows the official response formats: four choices for one answer, at least five choices when multiple answers are required. Review explains why each option fits or fails and provides exact course references and official AWS documentation.

The current diagnostic embeds related course visuals, labeled as such rather than showing earlier cards containing obsolete answer wording. The supplemental cases have dedicated answer visuals. Saved browser attempts made with the original questions continue to use the original copy, key, and answer visuals.
